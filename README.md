# Sites Nodes — эталоны сайтов для нод

Коллекция готовых статических сайтов, которые можно использовать как образец для новых локаций. Это исходники сайтов и инструкции по адаптации; настройки серверов сюда не входят.

## Каталог

| Название | Идентификатор | Локация | Каталог |
|---|---|---|---|
| **Stayroute NYC — City Guide** | `stayroute-nyc` | Нью-Йорк, США | [sites/stayroute-nyc](sites/stayroute-nyc) |

## Как сослаться на образец в другом чате Codex

> Возьми `Daniil-GR/sites_nodes`, эталон `stayroute-nyc` из `sites/stayroute-nyc`. Сделай сайт для указанной мной новой локации: сохрани дизайн, структуру страниц, интерактивные карты, прогулки, избранное и смену времени суток. Сначала прочитай AGENTS.md, README.md и ADAPTATION.md. Работай в отдельной копии; используй реальные места, координаты, подходящие изображения и заново рассчитанные пешеходные маршруты. Настройки и службы ноды не меняй. Сайт на действующей ноде публикуй только по прямому запросу.

Для новой локации сообщите Codex город/регион, домен и каталог рабочей копии. Если нужна публикация, укажите её отдельно и определите каталог назначения.

## Быстрый просмотр эталона

```bash
git clone https://github.com/Daniil-GR/sites_nodes.git
cd sites_nodes/sites/stayroute-nyc
python3 -m http.server 8080 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8080/`. При работе через SSH использовать локальный туннель, не меняя сетевые правила сервера.

## Правило хранения

Новые локации добавляются отдельными каталогами `sites/<идентификатор>`. Эталон Нью-Йорка сохраняется как самостоятельный воспроизводимый пример. Рабочие инструменты, резервные копии серверов и секреты в репозиторий не добавляются.
