# Stayroute NYC — City Guide

**Идентификатор: `stayroute-nyc`.** Эталон статического городского путеводителя для нод. Локация: Нью-Йорк, США.

Это копия опубликованной версии от 11 ноября 2026 года, включая настоящие карты и последнюю правку без флага/подписи Leaflet. 37 файлов сайта побайтово сверены с действующим каталогом; их SHA-256 указаны в `reference-manifest.json`. Служебные материалы репозитория находятся вне этого перечня и не меняют поведение сайта.

## Что можно воспроизвести

- Главная страница с четырьмя иллюстрированными состояниями света, часами и необязательной погодой.
- Explore с 18 местами, поиском, категориями, районами, выбором на карте и избранным.
- City Walks с семью прогулками и страницами маршрутов.
- Leaflet 1.9.4, настоящая подложка OpenStreetMap, кликабельные маркеры и локальные пешеходные GeoJSON.
- Страницы мест, журнал, статьи и сохранённые места.
- Светлая палитра, оранжевые акценты, текущие шрифты и адаптивная сетка.

Сайт на английском языке. Сервер приложения, база данных, сборка и обязательные npm-зависимости не нужны.

## Запуск

В этом каталоге:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8080/`. Через `file://` загрузка GeoJSON может блокироваться браузером, поэтому нужен обычный статический HTTP-сервер.

## Скопировать под другой город

Полностью скопируйте этот каталог в отдельную рабочую копию или `sites/<новый-id>`, прочитайте [ADAPTATION.md](ADAPTATION.md), затем замените географическое содержимое, сохранив дизайн и функции. Сам эталон не нужно превращать в другой город.

Значения Нью-Йорка сейчас встречаются не только в данных, но и в `js/site.js`, `js/maps.js`, HTML и иллюстрациях. Эта версия намеренно сохранена без универсализации, чтобы визуально и функционально совпадать с опубликованным сайтом.

## Проверки и инструменты

```bash
python3 tests/routes.py
node --check js/site.js
node --check js/maps.js
node --check js/data.js
```

Node здесь нужен только для необязательной проверки синтаксиса, а не для работы сайта. `scripts/build-routes.py` выполняет разовый расчёт; исходные ответы кэшируются в файлах. При изменении точек или параметров скрипт требует явно убрать устаревшие исходные ответы перед новым расчётом. После расчёта: `node scripts/update-route-metrics.cjs`, затем повторная проверка. Дополнительные проверки: `scripts/audit-route-edges.py`, `scripts/check-osm-access.py`. Для другой локации сначала исправьте входные данные и географические границы проверки.

## Внешние источники

Тайлы OSM, необязательные фотографии Unsplash, Google Fonts и Open-Meteo запрашиваются браузером. При отказе тайлов сохраняются маркеры и локальные линии с пояснением; офлайн-подложка не обещается. При отказе фотографий используются локальные иллюстрации, при отказе шрифта — системный шрифт, при отказе погоды остальные функции продолжают работать.
