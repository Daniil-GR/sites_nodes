# Внешние компоненты и данные

- **Leaflet 1.9.4**, BSD-2-Clause. Оригинальный текст лицензии сохранён в `vendor/leaflet/LICENSE`. Флаг и префикс Leaflet отключены штатным `setPrefix(false)`, без изменения библиотеки.
- **OpenStreetMap**: © OpenStreetMap contributors, ODbL 1.0. Атрибуция на карте сохранена. Геометрия и извлечения данных: `data/LICENSE.md`. Условия: https://www.openstreetmap.org/copyright.
- **Тайлы OSM**: https://operations.osmfoundation.org/policies/tiles/. Загружаются для видимой области с обычным браузерным кэшем и Referer. Массовое/предварительное скачивание тайлов не применяется. У публичного сервиса нет гарантии доступности.
- **Маршрутизация Valhalla / FOSSGIS**: https://valhalla.github.io/valhalla/start/introduction/. Результаты сохранены локально, посетители не обращаются к публичному маршрутизатору.
- **Фотографии Unsplash**: удалённые URL в `js/data.js`, https://unsplash.com/license. Не копируйте фотографии в новые продукты без проверки прав, условий использования и соответствия новой локации.
- **Google Fonts / Manrope**: необязательное внешнее подключение в CSS, системный шрифт используется при недоступности. Файлы шрифтов в репозитории не хранятся.
- **Open-Meteo**: необязательная модельная погода, https://open-meteo.com/en/docs. Перед новым использованием проверьте актуальные условия, включая атрибуцию и допустимый тип использования; бесплатность исходного запроса не гарантирует соответствие любого будущего коммерческого проекта условиям сервиса.

Не убирайте обязательную атрибуцию поставщиков карты. Отсутствие префикса Leaflet не означает разрешения удалить строку OpenStreetMap.
